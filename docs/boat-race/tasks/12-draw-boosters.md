# Draw Booster Arrows { .boat-task }

## Goal

Add white areas to the course where the boat will speed up.

## Do This

1. Select the **Stage** and open **Backdrops**.
2. Select the race course backdrop you are using.
3. Use the paint tools to draw white arrows on the water, like the example.
4. Keep a clear route past the wooden barriers and towards the island.
5. Return to **Code**.

![Race course with white booster arrows](../assets/boat-boost.png){ .example-image }

## Check

White booster arrows appear on the race course. They will change the boat’s speed after the next task.
