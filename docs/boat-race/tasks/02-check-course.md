# Check Your Race Course { .boat-task }

## Goal

Find the boat, barriers, and finish before adding code.

## Do This

1. Look at the Stage. Find the water, brown wooden barriers, and yellow island.
2. Find the boat in the sprite list below the Stage. Click its thumbnail.
3. Click **Code**. This is where you will build the boat’s movement script.
4. Plan a route from the bottom left of the course to the island without crossing the wood.

![Race course with boat, wooden barriers, and island](../assets/boat-starter.png){ .example-image }

## Check

You can point to the boat, explain what it must avoid, and show where it must finish.
