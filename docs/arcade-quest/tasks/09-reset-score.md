# Task 9: Reset `score`

## Goal

Make the score start at zero.

## Do This

1. In the sprite list below the Stage, click the `Coin` sprite, or click the Stage thumbnail. (If you cannot remember where the sprite list is, go back to [Start Here: Where To Click Sprites](../../index.md#where-to-click-sprites).)
2. Build this code.
3. Press the green flag.

![Scratch blocks for resetting the score](../assets/scratchblocks/score-start.png){ .scratch-image }

## Check

The `score` variable should change to `0` when the green flag is clicked.
