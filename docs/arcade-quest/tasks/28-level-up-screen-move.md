# Create A Scrolling Scene { .arcade-task }

## Goal

Create a new scene for a level that moves sideways.

## What This Means

The Scratch Stage does not really move. Instead, the `Player` stays near the middle of the screen, and the level sprites move left. In Part 9, you will build this one step at a time.

## Do This

1. Click the **Stage** thumbnail.
2. Click **Backdrops**.
3. Click **Choose a Backdrop**.
4. Click **Paint**.
5. Rename the new backdrop `Scrolling Level`.
6. Draw the sky and background.
7. Do not draw platforms on this backdrop.

## Check

You should have a backdrop called `Scrolling Level` with sky and scenery. Leave platforms off the backdrop so they can move as sprites.
