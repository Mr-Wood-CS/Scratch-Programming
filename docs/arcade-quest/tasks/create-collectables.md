# Create Collectables

## Goal

Create an object for the player to collect.

## Do This

1. Click **Choose a Sprite** below the Stage.
2. Click **Paint**.
3. Draw a small coin, gem, star or piece of fruit.
4. Rename the sprite `Coin`.
5. Put it above a platform.

!!! warning "Use a sprite"
    Do not paint the collectable on the backdrop. A separate sprite can detect the player, increase the score, play a sound and disappear.

## Check

The sprite list should contain separate `Player`, `Platforms` and `Coin` sprites.
