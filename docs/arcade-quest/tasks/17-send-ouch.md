# Task 17: Send `ouch`

## Goal

Make the enemy send a message when it touches the player.

## Do This

1. In the sprite list below the Stage, click the `Enemy` sprite. (If you cannot remember where the sprite list is, go back to [Start Here: Where To Click Sprites](../../index.md#where-to-click-sprites).)
2. Look at the enemy patrol code from Task 16.
3. Find the block that says `broadcast ouch`.
4. Make sure that block is inside the touching `Player` check.
5. Test by touching the enemy.

## Check

The enemy should send the `ouch` message when the player touches it.
