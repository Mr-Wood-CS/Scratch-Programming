# Make `scroll x` { .arcade-task }

## Goal

Create a variable to track how far the level has scrolled.

## Do This

1. Click **Variables**.
2. Click **Make a Variable**.
3. Name the variable `scroll x`.
4. Choose **For all sprites** so the player and level sprites can use the same value.
5. Click **OK**.

## Check

Select the `Player` and then `Platform 1`. The same `scroll x` variable should be available on both sprites.
