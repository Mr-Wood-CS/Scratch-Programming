# Create Scrolling Platforms { .arcade-task }

## Goal

Make three platform sprites that can move across the scrolling scene.

## Do This

1. Click **Choose a Sprite**.
2. Click **Paint**.
3. Draw one green rectangle platform.
4. Rename it `Platform 1`.
5. Right-click `Platform 1`.
6. Click **duplicate**.
7. Rename the copy `Platform 2`.
8. Right-click `Platform 2`.
9. Click **duplicate**.
10. Rename the copy `Platform 3`.
11. Put the three platforms across the new scene.

## Check

Your sprite list should contain `Platform 1`, `Platform 2`, and `Platform 3`. Each platform should be a separate sprite.
