# Task 10: Place Your First Coin

## Goal

Put the first collectable where the player can reach it.

## Do This

1. Drag the `Coin` sprite above a platform.
2. Choose a platform the `Player` can jump onto.
3. Make sure the coin is not inside the ground or inside a platform.
4. Test the jump.

## Check

The coin should be visible and reachable. It must appear in the sprite list as `Coin`.
