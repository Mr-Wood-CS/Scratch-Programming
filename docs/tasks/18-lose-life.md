# Task 18: Lose A Life

## Goal

Make the player lose one life after touching an enemy.

## Do This

1. In the sprite list below the Stage, click the `Player` sprite. (If you cannot remember where the sprite list is, go back to [Start Here: Where To Click Sprites](../index.md#where-to-click-sprites).)
2. Build this code.
3. Test by touching the enemy.

![Scratch blocks for losing a life](../assets/scratchblocks/lose-life.png){ .scratch-image }

## Check

The player should lose one life and return to the start.
