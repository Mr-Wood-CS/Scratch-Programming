# Task 24: Win At The Flag

## Goal

Make the player win when they touch the flag.

## Do This

1. [In the sprite list below the Stage](../index.md#where-to-click-sprites), click the `Player` sprite.
2. Use the flag part of the code from Task 23.
3. Make sure it checks `touching Flag`.
4. Make it broadcast `you win`.
5. Test by moving the player into the flag.

## Check

Touching the flag should send the `you win` message.
