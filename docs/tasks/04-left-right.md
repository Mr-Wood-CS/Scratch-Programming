# Task 4: Move Left And Right

## Goal

Make the player move with the arrow keys.

## Do This

1. [In the sprite list below the Stage](../index.md#where-to-click-sprites), click the `Player` sprite.
2. Build this code.
3. Press the green flag.
4. Test the left and right arrow keys.

![Scratch blocks for moving the player left and right](../assets/scratchblocks/player-move.png){ .scratch-image }

## Check

The player should move left and right.
