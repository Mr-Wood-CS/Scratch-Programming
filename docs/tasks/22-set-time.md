# Task 22: Set `time`

## Goal

Make the timer start at 60.

## Do This

1. [In the sprite list below the Stage](../index.md#where-to-click-sprites), click the `Player` sprite, or click the Stage thumbnail.
2. Add `when green flag clicked`.
3. Add `set time to 60`.
4. Press the green flag.

## Check

The `time` variable should show `60`.
