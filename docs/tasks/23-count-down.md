# Task 23: Count Down

## Goal

Make the timer count down.

## Do This

1. Click the `Player` sprite or the **Stage**.
2. Build the timer part of this code.
3. Press the green flag.
4. Watch the `time` variable.

![Scratch blocks for the timer and finish flag](../assets/scratchblocks/timer-and-finish.png){ .scratch-image }

## Check

The timer should go down by `1` every second.
