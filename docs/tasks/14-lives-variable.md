# Task 14: Make `lives`

## Goal

Create the variable that stores how many tries the player has.

## Do This

1. Click **Variables**.
2. Click **Make a Variable**.
3. Name the variable `lives`.
4. Choose **For all sprites**.
5. Click **OK**.

Use [Task 3: Make `y speed`](03-y-speed-variable.md) if you need to see the variable buttons again.

## Check

You should see a variable called `lives`.
