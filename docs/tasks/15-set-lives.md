# Task 15: Set `lives`

## Goal

Make the game start with three lives.

## Do This

1. [In the sprite list below the Stage](../index.md#where-to-click-sprites), click the `Player` sprite, or click the Stage thumbnail.
2. Add a `when green flag clicked` block.
3. Add `set lives to 3`.
4. Press the green flag.

## Check

The `lives` variable should show `3`.
