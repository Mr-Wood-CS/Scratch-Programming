# Task 7: Add A Coin

## Goal

Add a collectable item for the player to grab.

## Watch First

<iframe class="video-frame" src="https://www.youtube.com/embed/4v1CIKehF6E" title="YouTube video about making a Scratch clicker game with items and score" allowfullscreen></iframe>

## Do This

1. Click **Choose a Sprite**.
2. Click **Paint**.
3. Draw a small coin, gem, star, or fruit collectable.
4. Rename the sprite `Coin`.
5. Put it above a platform.

## Check

Your sprite list should contain a sprite called `Coin`.
