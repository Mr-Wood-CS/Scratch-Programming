# Task 12: Add Coin Sound

## Goal

Make collecting a coin feel satisfying.

## Do This

1. In the sprite list below the Stage, click the `Coin` sprite.
2. Click **Sounds**.
3. Choose or record a short sound.
4. Go back to **Code**.
5. Make sure your collect code includes `play sound coin until done`.
6. Test the game.

## Check

You should hear a sound when the player collects the coin.
